# v2 format

`config.json`:

- `"version": 2`
- `"db"`: `{ "host", "port", "name", "user" }` taken from the v1 URL; `port` is a number.
  The password is no longer stored: the app reads it from `DB_PASSWORD`.
- `"timeoutMs"`: v1 `"timeout"` (seconds) × 1000.

`data/users.json`: an array of `{ "first", "last", "email" }`.

- `first` = v1 `name` up to its first space; `last` = the rest, `""` when there is none.
- `email` is lowercased.

`node validate.mjs` checks the shape of both files.
