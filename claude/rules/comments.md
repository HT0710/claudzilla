# Comments & Docs

All languages. Code comments + docstrings. README/CHANGELOG → repo's own style.

- Default: no comment. Only non-obvious why.
- Inline comment: why only. Code shows what + how.
- Docstring / doc comment: one-line what. Params/returns only when not obvious from signature.
- No history: no "added in v2", "was X, now Y", "fixed bug where...". Git holds that. Version requirements OK.
- No prose explanation. Fragment or single sentence.
